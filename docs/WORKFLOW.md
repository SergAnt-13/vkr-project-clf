# Workflow

Этот документ описывает практический порядок работы с проектом без погружения в код.

## Базовая идея

У вас есть:

- файл, который нужно обработать
- возможно, отдельный файл, на котором нужно обучить модель

Проект умеет:

- использовать один и тот же файл и для обучения, и для предсказания
- использовать разные файлы для обучения и для предсказания

## Куда что класть

### Файл для обработки

Положить в:

- `data/to_process/`

По умолчанию проект ожидает:

- `data/to_process/Номенклатурные единицы.xlsx`

### Размеченный обучающий файл

Положить в:

- `data/training/`

По умолчанию merged-файл:

- `data/training/Номенклатурные единицы_merged.xlsx`

### Справочники

Лежат в:

- `data/reference/`

## Самый безопасный порядок запуска

### 1. Проверить источники

```bash
./venv/bin/python cli.py inspect-data
```

Эта команда:

- ничего не обучает
- ничего не портит
- показывает, какие файлы проект нашел
- показывает, сколько в них валидных кодов ОКПД2

### 2. Пробный запуск baseline на части данных

```bash
./venv/bin/python cli.py baseline --max-rows 500
```

Это проверка, что пайплайн живой.

### 3. Полный baseline

```bash
./venv/bin/python cli.py baseline
```

### 4. BERT на встроенных данных

```bash
./venv/bin/python cli.py bert --mode enhanced
```

### 5. BERT на отдельном размеченном файле

```bash
./venv/bin/python cli.py bert \
  --mode standard \
  --prediction-file "data/to_process/Номенклатурные единицы.xlsx" \
  --training-file "data/training/ИМЯ_ВАШЕГО_РАЗМЕЧЕННОГО_ФАЙЛА.xlsx"
```

## Если у вас появился новый почти правильный размеченный файл

Тогда логика такая:

- `--prediction-file` — файл, для которого нужен итоговый результат
- `--training-file` — файл, на котором нужно обучаться

Это ключевой режим для дальнейшего развития проекта.

## Где смотреть результаты

- baseline: `data/results/baseline/`
- bert: `data/results/bert/`
- модели BERT: `artifacts/models/bert_okpd/`

## Что важно не путать

- файл для обработки и обучающий файл не обязаны совпадать
- большое количество строк не всегда лучше маленькой качественной выборки
- для диплома важно сравнивать режимы на одном и том же prediction-файле

## Минимальный рабочий сценарий для вас

1. Положить актуальный файл для обработки в `data/to_process/`
2. Положить новый размеченный файл в `data/training/`
3. Выполнить `inspect-data`
4. Выполнить `baseline --max-rows 500`
5. Выполнить полный `baseline`
6. Выполнить `bert` на том же prediction-файле
7. Сравнить результаты моделей
8. После этого уже решать вопрос о замене BERT на другую модель
