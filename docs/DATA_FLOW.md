# Data Flow

Этот документ описывает, что проект берет на вход, как обрабатывает данные и что отдает на выходе.

## 1. Входные файлы

### Основной файл для обработки

Обычно это:

- `data/to_process/Номенклатурные единицы.xlsx`

Минимально проект ожидает колонку с названием товара.

Желательно также иметь:

- идентификатор позиции
- текущий код ОКПД2
- текущую ставку НДС

### Обучающий файл

Может быть одним из вариантов:

- тот же самый файл, который обрабатывается
- `data/training/Номенклатурные единицы_merged.xlsx`
- любой новый внешний размеченный файл, переданный через `--training-file`

### Справочники

Используются:

- `data/reference/сокращения.xlsx`
- `data/reference/Товары ставка 10%.xlsx`
- `data/reference/Постановление Правительства РФ ... .rtf`

## 2. Какие колонки ищет проект

Проект не привязан жестко к одному названию колонки. Он ищет похожие варианты.

Основные поля:

- идентификатор: `Идентификатор номенклатуры`, `id`, `Артикул`
- название: `Номенклатура`, `Наименование`
- текущий код: `Код ОКПД2`, `ОКПД2`
- текущий НДС: `Ставка НДС (Заказ)`, `Ставка НДС`
- эталонный код: `ОКПД2_эталон`
- эталонный НДС: `Ставка НДС_эталон`

## 3. Предобработка текста

Перед классификацией проект:

- приводит текст к нижнему регистру
- заменяет похожие латинские символы на кириллические
- применяет словарь сокращений
- убирает часть шумовых фрагментов
- нормализует пробелы и знаки

Цель предобработки — сделать похожие товары текстово более похожими друг на друга.

## 4. Как формируется обучающая выборка

### Baseline

Обучающая выборка состоит из строк, где уже есть валидный ОКПД2.

Если указан `--training-file`, то baseline учится на нем.

Если `--training-file` не указан, baseline учится на самом prediction-файле, используя уже размеченные строки внутри него.

### BERT Standard

BERT standard по умолчанию учится на текущих кодах ОКПД2 из основной номенклатуры.

### BERT Enhanced

BERT enhanced по умолчанию пытается учиться на эталонных метках из merged-файла.

### Внешний обучающий файл

Если вы передаете свой файл через `--training-file`, то он становится основным источником обучающих меток.

Это рекомендуемый режим для вашего дальнейшего развития проекта.

## 5. Как строится результат

### Baseline

На выходе формируются:

- предсказанный код ОКПД2
- уверенность модели
- итоговый код
- предсказанная ставка НДС
- аналитические таблицы расхождений

### BERT

На выходе формируются:

- предсказанный код ОКПД2
- уверенность предсказания
- итоговый код
- предсказанный и итоговый НДС
- Excel-файл результата
- текстовый отчет

## 6. Как считается НДС

Проект берет текст ПП-908, извлекает коды, строит набор префиксов для льготной ставки и затем проверяет, относится ли итоговый код товара к этим префиксам.

Если да, присваивается `НДС10`.

Если нет, присваивается `НДС20`.

## 7. Куда сохраняются результаты

- baseline: `data/results/baseline/`
- bert: `data/results/bert/`

## 8. Что является “истиной”, а что нет

Важно понимать:

- текущий код в основной номенклатуре не всегда является эталоном
- merged-файл выглядит более надежным источником для части строк
- новый почти корректный размеченный файл может быть намного ценнее шумной большой выборки

Поэтому проект уже подготовлен к работе с отдельной обучающей выборкой.
