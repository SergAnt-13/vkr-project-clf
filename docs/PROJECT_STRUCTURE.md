# Project Structure

## Корень проекта

В корне находятся:

- исполняемый код
- проектные настройки
- основная документация

То есть корень теперь не должен быть свалкой из Excel, логов и результатов.

## Код

- `cli.py` — единая CLI-точка входа
- `run.py` — интерактивное меню запуска
- `main.py` — совместимый запуск baseline
- `main_bert_unified.py` — совместимый запуск BERT с выбором режима
- `main_bert_okpd.py` — совместимый запуск BERT standard
- `pipelines.py` — прикладные сценарии работы
- `config.py` — пути, параметры и значения по умолчанию
- `data_loader.py` — загрузка файлов и приведение колонок к единой схеме
- `text_processor.py` — предобработка текста
- `okpd_classifier.py` — baseline-классификатор
- `bert_okpd_classifier.py` — BERT-классификатор
- `vat_processor.py` — расчет НДС
- `output_manager.py` — сохранение результатов и отчетов

## Документация

- `README.md` — общий обзор проекта
- `docs/WORKFLOW.md` — пошаговый сценарий запуска
- `docs/DATA_FLOW.md` — описание входов, обработки и выходов
- `docs/BUSINESS_CONTEXT.md` — описание системы на понятном языке
- `docs/GIT_PREP.md` — что можно и нельзя отправлять в Git
- `docs/BERT_NOTES.md` — краткая заметка по BERT

## Данные

### `data/to_process/`

Файлы, которые нужно обработать.

### `data/training/`

Размеченные или частично размеченные обучающие файлы.

### `data/reference/`

Справочники и нормативные источники:

- сокращения
- НДС-справочник
- ПП-908

### `data/results/`

Результаты новых запусков:

- `data/results/baseline/`
- `data/results/bert/`

## Артефакты

- `artifacts/models/bert_okpd/` — сохраненные модели BERT

## Архив

`archive/` содержит старые и нерабочие в текущем процессе вещи:

- старые выходные Excel-файлы
- старые отчеты
- старые логи
- старые вспомогательные данные
- локальные технические артефакты

Архив не должен участвовать в обычном запуске проекта.

## Что должно идти в Git

- код
- документация
- тесты
- проектные настройки

## Что не должно идти в Git

- реальные бизнес-данные
- результаты прогонов
- архив
- логи
- виртуальное окружение
- IDE-настройки
