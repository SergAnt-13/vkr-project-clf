# Data Layout

Каталог `data/` используется только для локальных данных и результатов.

## Подкаталоги

- `to_process/` — файлы, которые нужно обработать
- `training/` — обучающие и размеченные файлы
- `reference/` — справочники и нормативные файлы
- `results/` — результаты новых запусков

Этот каталог не предназначен для публикации в Git вместе с реальными данными.
